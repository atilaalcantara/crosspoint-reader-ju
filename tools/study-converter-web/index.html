    02 / Instalar no X4 Pro

    Do download ao dispositivo.

    Converta o pacote acima e siga estes três passos.

    1. Exporte pelo Anki

      No Anki Desktop: Arquivo → Exportar → Pacote de baralho Anki (.apkg). Sem informações de agendamento.

    2. Baixe o resultado

      Sem imagens, vem um .cps. Com imagens, vem um .zip — extraia e leve tudo. Áudio e LaTeX ficam de fora.

    3. Copie para o cartão SD

      Crie /study/ na raiz do SD e coloque o .cps lá (com a pasta .media ao lado, se houver). Em Home → File Transfer → USB Drive ou pelo Wi-Fi em Files. Depois é só abrir Study.
